ABOUT

POP BASE でできること

🏠

お店づくりは管理画面で

出品者さま専用の管理画面で、壁紙・色・看板・キャラクター・商品の並べ方を、プレビューを見ながらご自身で設定できます。

🗓️

期間限定のポップアップ

会期と営業時間を決めて開催します。オープン前は入口にカウントダウンが表示されます。

👋

お客さまどうしが同じ店内に

ほかのお客さまのアバターが見え、スタンプでやりとりできます。実際のお店のようなにぎわいが生まれます。

💳

お会計はそのまま購入まで

商品を選んでカートに入れ、クレジットカードなどで購入できます。決済の仕組みは POP BASE でご用意します。

📦

注文の確認もかんたん

管理画面で、ご注文の商品とお届け先を確認できます。CSV でダウンロードして、発送の作業に使えます。

FLOW

出品の流れ

  1. ご相談

    下のフォームから「出品について」ご連絡ください。商品の内容やご希望の時期をお聞かせください。

  2. メールでご案内

    内容を確認のうえ、会期や費用など出品の条件をメールでご案内します。

  3. 管理画面のアカウントをお渡し

    出品者さま専用の管理画面のアカウントをお渡しします。会期・送料・お支払い方法などは POP BASE が設定します。

  4. 商品の申請

    管理画面の「商品の申請」から、商品の情報（商品名・価格・在庫数・説明）と画像を登録してください。POP BASE が内容を確認して、お店の商品として登録します。

  5. お店づくり

    内装・入口の画面・キャラクター・棚の並べ方を、プレビューを見ながら設定します。できあがったら「反映の確認を依頼する」を押してください。POP BASE が確認して、オープンの準備が整います。

  6. オープン

    会期中、お客さまがアバターで来店し、お買い物を楽しみます。

  7. 発送

    管理画面の「注文」で、ご注文の商品とお届け先を確認して、出品者さまからお客さまへ直接発送していただきます。

  8. 会期終了

    会期が終わったら、売上についてご連絡します。

FAQ

よくあるご質問

費用はかかりますか？

費用は、出品の内容や期間に合わせて、メールで個別にご案内します。まずはお気軽にお問い合わせください。

お店づくりは自分でできますか？

はい。出品者さま専用の管理画面で、内装・入口の画面・キャラクター・棚の並べ方をご自身で設定できます。会期・送料・お支払い方法などの設定と、お客さまのサイトへの反映は POP BASE が行います。

商品の登録はどうすればいいですか？

管理画面の「商品の申請」から、商品の情報と画像を登録してください。POP BASE が内容を確認して、お店の商品として登録します。

商品の発送は誰がしますか？

ご注文の商品は、出品者さまからお客さまへ直接発送していただきます。ご注文の内容とお届け先は、管理画面の「注文」で確認でき、CSV でダウンロードもできます。

会期はどのくらいですか？

ご希望の時期をうかがったうえで、メールでご案内します。

法人・個人どちらでも出品できますか？

はい、企業さま・個人のクリエイターさま、どちらからのご相談も歓迎しています。
