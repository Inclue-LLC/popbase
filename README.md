# STUDIO HANEUL Virtual Pop-up Store

スタジオハヌルのバーチャルポップアップショップ。ビルド不要の静的サイト（HTML / CSS / JavaScript）です。

## 見る

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで確認する場合:

```bash
python3 -m http.server 8000
```

→ http://localhost:8000

GitHub Pages / Netlify / Cloudflare Pages などにそのまま置いて公開できます。

## できること

| エリア | 内容 |
| --- | --- |
| 入口 | 空のグラデーションとキャラクターのお出迎え、ドアが開く演出（セッション中は1回だけ表示） |
| フロアマップ | キャラクター別ブース・会場限定コーナー・レジ。ブースをクリックすると、その棚の商品に絞り込み |
| 商品一覧 | キャラクター／カテゴリ／会場限定で絞り込み、並び替え、NEW・残りわずか・SOLD OUT 表示 |
| 商品詳細 | 説明・仕様・在庫・数量選択。会場限定品は「お一人様 n 点まで」の上限を適用 |
| カート | 数量変更・削除、購入特典までの残額メーター、送料無料ライン、クーポンの自動適用 |
| クーポンガチャ | 1日1回、確率つきで割引クーポンが当たる（デモ用リセットボタン付き） |
| ご案内 | 会期・特典・送料・キャラクター紹介 |

カートとクーポンはブラウザの localStorage に保存されます。ライト／ダークモード、スマホ表示、「視差効果を減らす」設定に対応しています。

## 内容の差し替え

ほとんどの変更は **`js/data.js`** だけで済みます。

- `SHOP` … ブランド名、テーマ、会期、送料、購入特典の条件
- `CHARACTERS` … キャラクター名・カラー・プロフィール
- `CATEGORIES` / `PRODUCTS` … 商品（価格・在庫・会場限定・購入上限・NEW など）
- `GACHA_PRIZES` … ガチャの景品と出やすさ

### キャラクター・商品画像について

現在のキャラクター（ハル・ビョル・タルビ・ゴミ）と商品イラストは、**仮のオリジナルデザイン**を SVG で描画したもの（`js/art.js`）です。
実際のキャラクター・商品写真に置き換えるときは、`images/` フォルダに画像を置いて、商品に `image` を指定してください。

```js
{ id: 'p01', name: 'ハル もちもちぬいぐるみ M', image: 'images/p01.png', ... }
```

## 未実装（本番化するときに必要なもの）

- **決済**：「購入手続きへ」はデモの注文完了画面を出すだけです。Shopify（Buy Button / Storefront API）、STORES、BASE、Stripe Checkout などに接続してください。
- **在庫の共有**：在庫数は `data.js` の固定値で、購入するとそのブラウザ内でだけ減ります。実在庫はEC側から取得する必要があります。
- **ガチャの不正対策**：1日1回の制限はブラウザ側のみです。本番でクーポンを発行するならサーバー側で管理してください。

## ファイル構成

```
index.html      ページ構造
css/style.css   デザイン（色はファイル先頭の CSS 変数で管理）
js/data.js      ショップ設定・キャラクター・商品データ
js/art.js       キャラクター・商品の SVG イラスト
js/app.js       フロアマップ、絞り込み、カート、ガチャなどの動き
```
