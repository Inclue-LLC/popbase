# STUDIO HANEUL Virtual Pop-up Store

スタジオハヌルのバーチャルポップアップショップ。
お客さんはキャラクターのアバターで 3D の店内を歩き、棚の商品を手に取って購入できます。
同じ時間にいる他のお客さんのアバターも見え、スタンプで反応し合えます。

## 全体の構成

```
お客さんのブラウザ
 ├─ 3D 店内（Three.js）……… アバターで歩く・棚の商品を手に取る
 │                              レジ（カート）・ガチャ機（クーポン）も店内に
 │
 ├──▶ Shopify（Storefront API）… 商品・価格・在庫・購入手続き
 │                              店内の置き場所（商品メタフィールド）
 │                              会期・内装テーマ・壁紙（メタオブジェクト）
 │
 └──▶ 同時接続サーバー（server/）… 他のお客さんの位置・スタンプを中継
```

| 管理するもの | どこで | 誰が |
| --- | --- | --- |
| 商品・価格・在庫・画像・決済 | Shopify 管理画面（いつもの商品管理） | 社内スタッフ |
| 店内の置き場所・並び順・購入上限 | Shopify 管理画面（商品メタフィールド） | 社内スタッフ |
| 会期・壁紙・床・色・看板の文字 | Shopify 管理画面（メタオブジェクト「POP UPイベント」） | 社内スタッフ |
| 内装テーマのひな形・キャラクター | `js/themes.js`・`js/data.js`・`js/art.js` | 技術担当 |
| 同時接続サーバー | `server/index.js` | 技術担当 |

Shopify の設定手順とスタッフ向けの操作は **[docs/shopify-setup.md](docs/shopify-setup.md)** にまとめています。
Shopify を設定しない間は、`js/data.js` の見本データ（デモ用の注文完了画面）で動きます。

## 動かす

Node.js 18 以上が必要です。

```bash
npm install
```

```bash
npm start
```

→ http://localhost:8080 （サイトと同時接続サーバーが一緒に起動します）

別のブラウザ（またはシークレットウィンドウ）でもう1つ開くと、お互いのアバターが見えます。

> 3D 店内は ES モジュールを使うため、`index.html` をファイルとして直接開くと表示されません。必ずサーバー経由で開いてください。

### 公開する

サーバー1つで **サイト配信と同時接続の両方** を行います。Node.js と WebSocket が動くサービスならどこでも公開できます
（例: Render、Fly.io、Google Cloud Run、Railway、VPS など）。

| 環境変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | 8080 | 待ち受けポート |
| `ROOM_CAPACITY` | 30 | 1部屋（チャンネル）の最大人数。超えると自動で次のチャンネルに分かれます |
| `MAX_PER_IP` | 6 | 同じ IP からの同時接続の上限 |
| `ALLOWED_ORIGINS` | なし | 接続を許可するサイトの URL（カンマ区切り）。本番では設定を推奨 |

サイトだけを別の場所（Shopify のページ、GitHub Pages など）に置く場合は、`js/data.js` の `SHOP.multiplayerUrl` に
サーバーの URL（例: `wss://popup-server.example.com/ws`）を書きます。サーバーにつながらないときは、
「ひとりで見ています」と表示されて、そのまま店内を歩けます。

状態確認: `/healthz` で、部屋ごとの人数が JSON で返ります。

## できること

| エリア | 内容 |
| --- | --- |
| 入口 | テーマ色のグラデーションとキャラクターのお出迎え、ドアが開く演出 |
| 3D 店内 | アバター（4キャラ × 12種類のおなまえ）を選んで入店。左右の棚・会場限定テーブル・レジ・ガチャ機。棚に近づくと「この商品を見る」、クリックでも詳細が開く。全画面表示でも商品詳細・カート・ガチャがそのまま開く |
| 同時接続 | 他のお客さんのアバターと名前が見える。スタンプ 6 種。30人ごとにチャンネル自動分割 |
| 商品詳細・カート | 数量選択、お一人様の購入上限、特典までの残額メーター、送料無料ライン、クーポン自動適用 |
| 購入手続き | Shopify 連携時は Shopify のチェックアウトへ（ガチャのクーポンコードも自動で付く） |
| クーポンガチャ | 店内のガチャ機で1日1回、確率つきで割引クーポンが当たる |
| 壁のキャラクター | 話しかけるとプロフィールが出る |

商品は店内の棚でだけ販売しています（いわゆる「商品一覧ページ」はありません）。お店を歩いて探す体験を大切にするためです。

### 操作

| | PC | スマホ |
| --- | --- | --- |
| 歩く | WASD / 矢印キー、床をクリック（1回で約1.5m進む） | 左下のスティック、床をタップ（1回で約1.5m進む） |
| 視点 | ドラッグ（店内をつかんで動かす向き）、Q / E、ホイールでズーム | スワイプ |
| 全画面 | 右上の「全画面」 | 右上の「全画面」（iPhone でも画面いっぱいに表示） |
| カート | 右上の「カート」、またはレジに近づく | 同じ |
| 商品を見る | 近づいて Enter、または商品をクリック | 近づいて表示されるボタン、または商品をタップ |
| スタンプ | 右下のボタン、1〜6 キー | 右側のボタン |

### 荒らし対策

同時接続でやり取りするのは **位置・アバターの種類・おなまえの番号・スタンプの番号だけ** です。
自由入力のチャットや名前はないので、不適切な書き込みは起こりません。サーバー側でも値の範囲チェック、
送信回数の制限、IP ごとの接続数制限を行っています。

## 内装テーマ

テーマのひな形は **`js/themes.js`** にあります（`sky` / `night` / `holiday` / `spring`）。
イベントごとの細かい変更（壁紙画像・色・会期・看板の文字）は、Shopify のメタオブジェクトでひな形を上書きします。

- 確認用: URL に `?theme=night` を付ける、または店内の下の「内装テーマ（確認用）」で切り替え（Shopify 連携時は非表示）
- 新しいひな形: 既存テーマをコピーして色・柄・吊り飾りを変更

| キー | テーマ | 壁 | 床 | 吊り飾り |
| --- | --- | --- | --- | --- |
| `sky` | Sky Walk 空のおさんぽ | 雲柄 | 木目 | 雲・風船 |
| `night` | Starry Night 星降る夜のおさんぽ | 星柄（夜の照明・ネオン看板） | カーペット | 星・月 |
| `holiday` | Holiday Party ハヌルのホリデーパーティー | ストライプ＋緑の腰壁 | 赤白チェック | オーナメント・雪 |
| `spring` | Spring Picnic はるのピクニック | 花柄 | タイル | 花・ハート・風船 |

## キャラクター・アバターについて

キャラクター（ハル・ビョル・タルビ・ゴミ）は **仮のオリジナルデザイン** です（`js/art.js` の SVG）。
アバターは 3D モデルではなく、キャラクターの絵を「常にこちらを向く立体の板」にして歩かせています。
実際のキャラクターに差し替えるときは、`js/data.js` の `CHARACTERS` と `js/art.js` の絵を入れ替えてください
（将来 3D モデル（glTF）を用意した場合も、`js/world/avatars.js` の差し替えで対応できます）。

## ファイル構成

```
index.html            ページ構造
css/style.css         ページ全体のデザイン
css/world.css         3D 店内の画面（HUD・アバター選択・スティック）
js/data.js            ショップ設定・キャラクター・見本の商品・Shopify 設定
js/themes.js          内装テーマのひな形・棚のレイアウト
js/shopify.js         Shopify 連携（商品・イベント設定の読み込み、購入手続き）
js/art.js             キャラクター・商品の SVG イラスト
js/app.js             商品詳細・カート・ガチャ
js/world/main.js      3D 店内の進行（カメラ・移動・近くの商品・同時接続）
js/world/room.js      店内の組み立て（壁・棚・テーブル・レジ・ガチャ・飾り）
js/world/textures.js  壁紙・床・看板・値札・商品画像を canvas で描く
js/world/avatars.js   アバター・おなまえ・スタンプ
js/world/controls.js  キーボード・スティック・ドラッグ・タップ
js/world/net.js       同時接続クライアント
server/index.js       サイト配信＋同時接続サーバー
vendor/               three.js（npm run vendor で node_modules から更新）
docs/shopify-setup.md Shopify の設定手順・スタッフ向け運用
```

## 今後の拡張候補

- **ドラッグで配置できるレイアウト編集画面**：今は「置き場所＋並び順」を Shopify で選ぶ方式です。
  店内を見ながら商品をドラッグで置きたい場合は、Shopify のカスタムアプリ（管理画面に埋め込む画面）として追加できます。
- **ガチャのサーバー抽選**：今はブラウザで抽選しているため、クーポンコード自体の共有は防げません。
  1回限りのコードをサーバーで発行する仕組みにすると、より安全です。
- **キャラクターの 3D モデル化**、**フォトスポット**、**イベント時のキャラクター来店（スタッフアバター）** など。
