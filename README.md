# STUDIO HANEUL Virtual Pop-up Store

スタジオハヌルのバーチャルポップアップショップ。ビルド不要の静的サイト（HTML / CSS / JavaScript）です。

## 見る

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで確認する場合:

```bash
python3 -m http.server 8000
```

→ http://localhost:8000

GitHub Pages / Netlify / Cloudflare Pages などにそのまま置いて公開できます。
店内は CSS 3D で描いているため、最新の Chrome / Safari / Edge / Firefox で表示できます。

## できること

| エリア | 内容 |
| --- | --- |
| 入口 | 空のグラデーションとキャラクターのお出迎え、ドアが開く演出（セッション中は1回だけ表示） |
| 店内（3D） | 実際のお店のような空間。左右の壁の棚・中央の会場限定テーブル・レジ・ガチャ機に商品が並び、視点を切り替えて歩き回れる（← → キー対応）。棚の商品をクリックで詳細、レジでカート、壁のキャラクターでそのキャラの商品一覧へ |
| 商品一覧 | キャラクター／カテゴリ／会場限定で絞り込み、並び替え、NEW・残りわずか・SOLD OUT 表示 |
| 商品詳細 | 説明・仕様・在庫・数量選択。会場限定品は「お一人様 n 点まで」の上限を適用 |
| カート | 数量変更・削除、購入特典までの残額メーター、送料無料ライン、クーポンの自動適用 |
| クーポンガチャ | 1日1回、確率つきで割引クーポンが当たる（デモ用リセットボタン付き） |
| ご案内 | 会期・特典・送料・キャラクター紹介 |

カートとクーポンはブラウザの localStorage に保存されます。ライト／ダークモード、スマホ表示、「視差効果を減らす」設定に対応しています。

## 内装テーマ（POP UP ごとの壁面・床・飾り）

店内の内装は **`js/themes.js`** で管理しています。用意しているテーマは4つです。

| キー | テーマ | 壁 | 床 | 吊り飾り |
| --- | --- | --- | --- | --- |
| `sky` | Sky Walk 空のおさんぽ | 雲柄 | 木目 | 雲・風船 |
| `night` | Starry Night 星降る夜のおさんぽ | 星柄（夜の照明・ネオン看板） | カーペット | 星・月 |
| `holiday` | Holiday Party ハヌルのホリデーパーティー | ストライプ＋緑の腰壁 | 赤白チェック | オーナメント・雪 |
| `spring` | Spring Picnic はるのピクニック | 花柄 | タイル | 花・ハート・風船 |

- 使うテーマ: `js/data.js` の `SHOP.theme` を変更（例: `theme: 'holiday'`）
- URL でも確認できます: `index.html?theme=night`
- 店内の下にある「内装テーマ」のセレクトでもその場で切り替えられます（確認用。本番で不要なら `index.html` の `.theme-switch` を削除）

新しい POP UP 用のテーマは、既存のテーマをコピーして色・柄を変えるだけで作れます。
壁紙や床に**実際のデザイン画像**を使う場合は `wall.image` / `floor.image` に画像パスを指定してください（柄より優先されます）。

```js
autumn: {
  name: 'Autumn Walk', title: '秋のおさんぽ',
  wall: { color: '#f6e6d0', image: 'images/wall-autumn.png', lower: '#8a5a3c', trim: '#d08a4a' },
  floor: { style: 'wood', colors: ['#c99a6a', '#b88a5a'] },
  ...
}
```

どの商品をどこに並べるかは `STORE_LAYOUT`（左の棚・右の棚のカテゴリ）で決まります。会場限定品は中央のテーブルに並びます。商品ごとに `display: 'left' | 'right' | 'island'` を指定すると個別に置き場所を変えられます。

## 内容の差し替え

ほとんどの変更は **`js/data.js`** だけで済みます。

- `SHOP` … ブランド名、内装テーマ、会期、送料、購入特典の条件
- `CHARACTERS` … キャラクター名・カラー・プロフィール
- `CATEGORIES` / `PRODUCTS` … 商品（価格・在庫・会場限定・購入上限・NEW など）
- `GACHA_PRIZES` … ガチャの景品と出やすさ

### キャラクター・商品画像について

現在のキャラクター（ハル・ビョル・タルビ・ゴミ）と商品イラストは、**仮のオリジナルデザイン**を SVG で描画したもの（`js/art.js`）です。
実際のキャラクター・商品写真に置き換えるときは、`images/` フォルダに画像を置いて、商品に `image` を指定してください。

```js
{ id: 'p01', name: 'ハル もちもちぬいぐるみ M', image: 'images/p01.png', ... }
```

## 未実装（本番化するときに必要なもの）

- **決済**：「購入手続きへ」はデモの注文完了画面を出すだけです。Shopify（Buy Button / Storefront API）、STORES、BASE、Stripe Checkout などに接続してください。
- **在庫の共有**：在庫数は `data.js` の固定値で、購入するとそのブラウザ内でだけ減ります。実在庫はEC側から取得する必要があります。
- **ガチャの不正対策**：1日1回の制限はブラウザ側のみです。本番でクーポンを発行するならサーバー側で管理してください。

## ファイル構成

```
index.html      ページ構造
css/style.css   ページ全体のデザイン（色はファイル先頭の CSS 変数で管理）
css/store.css   3D 店内のデザイン
js/data.js      ショップ設定・キャラクター・商品データ
js/themes.js    内装テーマ・店内レイアウト
js/art.js       キャラクター・商品の SVG イラスト
js/store.js     3D 店内の組み立てと視点移動
js/app.js       絞り込み、商品詳細、カート、ガチャなどの動き
```
