# 店内管理画面の使い方（スタッフ向け）

店内管理画面では、次の内容をプレビューを見ながら変更できます。

| タブ | 変更できること |
| --- | --- |
| 商品の配置 | 棚・テーブルにどの商品を置くか |
| 内装・イベント | 会期・看板・壁紙・床・色・照明・**ショップの基本フォント**・購入特典 |
| 入口の画面 | お客さんが最初に見る「お店に入る」前の画面の文字・画像・色 |
| キャラクター | キャラクター紹介・入口に並ぶキャラクターの名前・プロフィール・色・イラスト・表示する/しない |
| アバター | お客さんが入店するときに選べるアバター（キャラクターとは別に設定。画像から追加もできる） |

- 開き方：サイトのアドレスの後ろに `/admin` を付けて開きます（例: `https://popup.example.com/admin`）
- 商品そのもの（名前・価格・在庫・写真）は、これまでどおり **Shopify 管理画面** で編集します

## 入力欄の「必須」「任意」

入力欄の名前の横に、次の印が付いています。

| 印 | 意味 |
| --- | --- |
| **必須** | 入れないと公開できません（ブランド名・イベント名・開始日時・終了日時） |
| **任意・空欄なら○○** | 空欄のままなら ○○（テーマの色・初期の文字など）が使われます |
| **任意・空欄なら非表示** | 空欄のままなら店内に表示しません（サブタイトル・特典の名前・入口のお知らせ） |

必須の欄が空欄のときは、画面上部に「必須項目が未入力」と表示され、その欄が赤くなります。

## 基本の流れ

```
編集する → 自動で下書きに保存 → 「下書きをサイトで確認」 → 「公開する」でお客さんに反映
```

- 編集した内容は、1秒ほどで自動的に **下書き** として保存されます（保存ボタンはありません）
- 下書きは、**「公開する」を押すまでお客さんには見えません**
- 画面上部の表示で状態がわかります
  - 「未公開の変更があります」… 下書きに、まだ公開していない変更がある
  - 「公開中と同じ内容です」… 下書きと公開中が同じ

## 商品の配置

左に商品の一覧、右に「左の棚」「会場限定テーブル」「右の棚」の枠があります。
棚は 3段 × 5枠、テーブルは 5枠です。

| やりたいこと | 操作 |
| --- | --- |
| 商品を置く | 左の一覧から枠へドラッグ（または、商品をクリック → 枠をクリック） |
| 置き場所を動かす | 枠から別の枠へドラッグ。商品がある枠に落とすと入れ替わります |
| 店内から外す | 枠の右上の「×」、または枠から左の一覧へドラッグ |
| まだ置いていない商品を探す | 一覧の上の「未配置だけ」にチェック |
| 最初からやり直す | 「自動で並べ直す」（商品の種類に合わせて自動で並べます） |

- 一覧の商品の下に「左の棚 下段 2番」のように、今の置き場所が表示されます
- 置いていない商品は、お客さんのサイトには表示されません

## 内装・イベント

| 項目 | 内容 |
| --- | --- |
| ブランド名 | 店内の看板の上の行、ページ上部のロゴ、入口の大きい見出し（入口で別に設定していない場合）。全角15文字・半角30文字まで |
| イベント名 | 店内の看板の大きい文字と入口。長さに合わせて看板の幅が広がります。全角14文字・半角28文字まで |
| サブタイトル | 看板の下の行（空欄なら表示しません。全角20文字・半角40文字まで） |
| 開始日時・終了日時 | この時間だけお店が開きます（日本時間）。開始前は入口に「○日 ○時 オープン」、終了後は「このポップアップは終了しました」と表示され、入店できません |
| 毎日の開店・閉店時刻 | 会期中の毎日の営業時間。空欄なら会期中は24時間営業。営業時間外は「本日の営業は終了しました」と表示 |
| 会期の表示文 | 看板の右の札・入口・ご案内に出す文。空欄なら日時から自動で作ります |

閉店の5分前から、店内に「閉店まで」のタイマーが出て、閉店時刻になると店内のお客さんは自動で退店します（カートは空になります）。
入力欄の下の「この設定で公開すると、今は ○○」で、公開したときの状態を確認できます。
| ベースのテーマ | 雲・星空・ホリデー・春の4種類から選びます。ほかの項目で空欄のものは、このテーマの値になります |
| 壁紙の画像 | 横長の画像（例: 2048×540px）。横に繰り返して貼られます。指定すると「壁の柄」より優先されます |
| 壁の色・柄・腰壁・見切りの色 | 画像を使わないときの壁のデザイン |
| 床の画像・種類・色 | 床のデザイン |
| 看板の色・照明 | 「夜」にすると店内が暗くなり、棚にスポットライトが当たります |
| 棚の看板 | 左右の棚の上の看板の文字 |
| フォント | ショップ全体の文字（入口・メニュー・商品詳細・店内の看板や値札）。丸ゴシック・明朝・手書き風など10種類から選べます |
| 購入特典 | 「あと○円で特典」の金額と特典の名前。特典の名前が空欄なら、カートやご案内に特典は表示しません |

- 色は「テーマの色に戻す」で、ベースのテーマの色に戻せます
- 画像は PNG・JPEG・WebP、8MB までです

## 入口の画面

お客さんが最初に見る画面です。右のプレビューは実際の画面と同じ表示で、「PC」「スマホ」で見え方を切り替えられます。

| 項目 | 内容 |
| --- | --- |
| 上の小さい文字・大きい見出し・見出しの下の文字 | 空欄なら「Virtual Pop-up Store」「STUDIO HANEUL」「イベント名 ― サブタイトル」 |
| お知らせ | 会期の下に表示する短いお知らせ（改行できます。空欄なら表示しません） |
| ボタンの文字 | 空欄なら「お店に入る」 |
| ロゴ画像 | 大きい見出しの代わりに表示（背景が透明な PNG がおすすめ） |
| 背景の画像 | 画面いっぱいに表示。設定すると背景の色と雲の飾りは表示しません |
| 背景の色・文字の色 | 背景のグラデーションの上下の色、見出しとそのほかの文字の色 |
| キャラクター | キャラクターの絵を表示するかどうか |

背景の画像を使うときは、文字が読みやすいか、プレビューの「スマホ」でも確認してください（スマホでは画像の左右が切れて表示されます）。

## キャラクター

ご案内の「キャラクター紹介」、入口、店内の正面の壁の絵に反映されます（どこも同じキャラクターが並びます）。
アバターとして選べるかどうかは、次の「アバター」タブで別に設定します。

| 項目 | 内容 |
| --- | --- |
| 画像を選ぶ | イラストを画像に差し替えます（背景が透明な正方形の PNG がおすすめ）。「元の絵に戻す」で戻せます |
| 名前・英語名・プロフィール・色 | 空欄なら元のまま |
| 表示しない | 紹介・入口・壁の絵から外します。商品とアバターはそのまま残ります |

キャラクターの追加はこの画面ではできません（技術担当にご相談ください）。

## アバター

お客さんが入店するときに選べるアバターを設定します。キャラクター紹介・入口とは別の設定です。
右側に、お客さんのアバター選びの画面がそのまま表示されます。

| やりたいこと | 操作 |
| --- | --- |
| キャラクターをアバターから外す／戻す | 「キャラクターのアバター」で「アバターとして選べる」のチェックを外す／付ける |
| 新しいアバターを追加する | 「＋ 画像からアバターを追加」で画像を選び、名前（12文字まで）を付ける |
| 並び順を変える | ↑ ↓ ボタン |
| 削除する | 「削除」。そのアバターで入店中のお客さんは、最初のアバターの見た目になります |

- 追加できるのは12個までです
- 画像は、正面を向いた絵で、背景が透明な正方形の PNG（512×512px 程度）がおすすめです。足元が画像の下端に来るようにすると、床にきれいに立ちます
- 名前が空のアバターがあると保存されません
- キャラクターのアバターの名前と絵は、「キャラクター」タブの設定に合わせて変わります

## 確認と公開

1. 画面右のプレビューで見た目を確認します（「左の棚」「テーブル」などで視点を切り替え、ドラッグで向きを変えられます）
2. 「**下書きをサイトで確認**」を押すと、新しいタブで実際のサイトが下書きの内容で開きます（上に「下書きのプレビュー中です」と表示されます）
3. 問題なければ「**公開する**」を押します。お客さんのサイトにすぐ反映されます

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 公開前の状態に戻したい | 「公開の履歴」タブ →「公開中の内容に戻す」で、下書きを捨てて公開中の内容に戻せます |
| 「他のスタッフが先に変更を保存しました」と出た | 同時に別のスタッフが編集しています。画面が最新の内容に読み込み直されるので、必要な変更をもう一度行ってください |
| 公開したのにサイトが変わらない | お客さん側のページを再読み込みしてください |
| ログインできない | 15分の間に10回失敗すると、しばらくログインできなくなります。時間をおいてください。パスワードを忘れた場合は技術担当に再設定を依頼してください |

## アカウントの管理（技術担当）

アカウントはサーバーのフォルダで次のコマンドで管理します。パスワードは10文字以上です。

```bash
npm run admin:user -- 名前
```

```bash
npm run admin:user -- --list
```

```bash
npm run admin:user -- --delete 名前
```

同じ名前でもう一度実行すると、パスワードの変更になります。削除したアカウントは、ログイン中でもすぐに使えなくなります。
