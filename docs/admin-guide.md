# 店内管理画面の使い方（スタッフ向け）

店内管理画面では、次の内容をプレビューを見ながら変更できます。

| タブ | 変更できること |
| --- | --- |
| 商品の配置 | 棚・テーブルにどの商品を置くか |
| 内装・イベント | 会期・看板・壁紙・床・色・照明・**ショップの基本フォント**・購入特典 |
| 入口の画面 | お客さんが最初に見る「お店に入る」前の画面の文字・画像・色 |
| キャラクター | イベントごとのキャラクターの登録（追加・削除・並び順・名前・プロフィール・色・イラスト）。キャラクターを使わない設定も |
| アバター | お客さんが入店するときに選べるアバター（キャラクターとは別に設定。画像から追加もできる） |

- 開き方：サイトのアドレスの後ろに `/admin` を付けて開きます（例: `https://popup.example.com/admin`）
- 商品そのもの（名前・価格・在庫・写真）は、これまでどおり **Shopify 管理画面** で編集します

## イベントごとの管理

ポップアップ（イベント）ごとに、内装・棚の配置・入口の画面・キャラクター・アバター・会期を別々に設定できます。
ログインすると、最初に **イベント一覧** が出ます。「開催中」「開催予定」「準備中（未公開）」「終了」に分かれて並び、
いまお客さんに出ているイベントには「お客さんに表示中」と付きます。「編集する」でそのイベントの編集画面に進みます。
編集画面の左上の「← イベント一覧」で一覧に戻れます（上部の「イベント」の選択欄で、ほかのイベントに直接切り替えることもできます）。

| やりたいこと | 操作 |
| --- | --- |
| 新しいイベントを作る | イベント一覧の「＋ 新しいイベント」→ イベント名を入れる |
| 前のイベントの設定を引き継いで作る | イベント一覧で引き継ぎたいイベントの「複製」（編集画面では「このイベントを複製」）。内装・入口の画面・キャラクター・アバター・棚の配置などがコピーされます（イベント名・サブタイトル・会期・営業時間・コレクションは新しく設定） |
| 店内に並べる商品を決める | 「内装・イベント」→「**Shopify のコレクション**」で、Shopify で作ったコレクションを選ぶ（必須） |
| イベントを削除する | 「削除」。お客さんに表示中のイベントは削除できません |

**お客さんのサイトに出るイベントは、会期で自動で決まります。**

1. 公開したイベントのうち、**会期中**（開始日時〜終了日時）のもの
2. 会期中のものがなければ、**次に始まる**もの（入口に「まもなくオープン」）
3. それもなければ、**最後に終わった**もの（入口に「このポップアップは終了しました」）

次のイベントは、前もって作って「公開する」まで済ませておけば、開始日時になると自動で切り替わります。
イベント名の横の［開催中］［開催予定］［終了］［未公開］で状態がわかります。「お客さんに表示中」が付いているものが、いまサイトに出ているイベントです。

### Shopify のコレクションの準備

1. Shopify の「商品管理 → コレクション」で、イベントごとにコレクションを作り（例：「春のフェア」）、そのイベントで売る商品を入れます
2. 商品とコレクションが、販売チャネル「Headless」に公開されていることを確認します
3. 店内管理画面でイベントを選び、「Shopify のコレクション」でそのコレクションを選びます。「商品の配置」に、そのコレクションの商品が並びます

## 入力欄の「必須」「任意」

入力欄の名前の横に、次の印が付いています。

| 印 | 意味 |
| --- | --- |
| **必須** | 入れないと公開できません（ブランド名・イベント名・開始日時・終了日時） |
| **任意・空欄なら○○** | 空欄のままなら ○○（テーマの色・初期の文字など）が使われます |
| **任意・空欄なら非表示** | 空欄のままなら店内に表示しません（サブタイトル・入口のお知らせ） |

必須の欄が空欄のときは、画面上部に「必須項目が未入力」と表示され、その欄が赤くなります。

## 基本の流れ

```
編集する → 自動で下書きに保存 → 「下書きをサイトで確認」 → 「公開する」でお客さんに反映
```

- 編集した内容は、1秒ほどで自動的に **下書き** として保存されます。画面上部の「**保存**」ボタン（または Ctrl+S / ⌘+S）で、すぐに保存することもできます（保存が済むと「保存済み ✓」になります）
- 下書きは、**「公開する」を押すまでお客さんには見えません**
- 画面上部の表示で状態がわかります
  - 「未公開の変更があります」… 下書きに、まだ公開していない変更がある
  - 「公開中と同じ内容です」… 下書きと公開中が同じ

## 商品の配置

左に商品の一覧、右に「左の棚」「会場限定テーブル」「右の棚」の枠があります。
棚は 3段 × 5枠、テーブルは 5枠です。

| やりたいこと | 操作 |
| --- | --- |
| 商品を置く | 左の一覧から枠へドラッグ（または、商品をクリック → 枠をクリック） |
| 置き場所を動かす | 枠から別の枠へドラッグ。商品がある枠に落とすと入れ替わります |
| 店内から外す | 枠の右上の「×」、または枠から左の一覧へドラッグ |
| まだ置いていない商品を探す | 一覧の上の「未配置だけ」にチェック |
| 最初からやり直す | 「自動で並べ直す」（商品の種類に合わせて自動で並べます） |

- 一覧の商品の下に「左の棚 下段 2番」のように、今の置き場所が表示されます
- 置いていない商品は、お客さんのサイトには表示されません

## 内装・イベント

| 項目 | 内容 |
| --- | --- |
| ブランド名 | 店内の看板の上の行、ページ上部のロゴ、入口の大きい見出し（入口で別に設定していない場合）。全角15文字・半角30文字まで |
| イベント名 | 店内の看板の大きい文字と入口。長さに合わせて看板の幅が広がります。全角14文字・半角28文字まで |
| サブタイトル | 看板の下の行（空欄なら表示しません。全角20文字・半角40文字まで） |
| 開始日時・終了日時 | この時間だけお店が開きます（日本時間）。開始前は入口に「○日 ○時 オープン」、終了後は「このポップアップは終了しました」と表示され、入店できません |
| 毎日の開店・閉店時刻 | 会期中の毎日の営業時間。空欄なら会期中は24時間営業。営業時間外は「本日の営業は終了しました」と表示 |
| 会期の表示文 | 看板の右の札・入口・ご案内に出す文。空欄なら日時から自動で作ります |

閉店の5分前から、店内に「閉店まで」のタイマーが出て、閉店時刻になると店内のお客さんは自動で退店します（カートは空になります）。
入力欄の下の「この設定で公開すると、今は ○○」で、公開したときの状態を確認できます。
| ベースのテーマ | Milk Tea（初期設定）・Soft Pink・Lavender Dream・Sage Mint・Powder Blue の5種類から選びます。壁・床・看板などの色を個別に指定しているときは、テーマを変えると「テーマの配色にそろえますか？」と確認が出ます（OKで個別の色を消してテーマの色に）。ほかの項目で空欄のものは、このテーマの値になります |
| 壁紙の画像 | 横長の画像（例: 2048×540px）。横に繰り返して貼られます。指定すると「壁の柄」より優先されます |
| 壁の色・柄・腰壁・見切りの色 | 画像を使わないときの壁のデザイン |
| 床の画像・種類・色 | 床のデザイン |
| 会場限定テーブルの下の色 | テーブルの下に敷く楕円の色。空欄ならテーマの色（少し透けた色） |
| 看板の色・照明 | 看板の地の色、正面の看板のイベント名の色・ブランド名の色（棚やテーブルの看板の文字はテーマの色）。照明を「夜」にすると店内が暗くなり、棚にスポットライトが当たります |
| 棚の看板 | 左右の棚の上の看板の文字（日本語・英字）。空欄の行は表示せず、日本語・英字とも空欄なら看板を出しません |
| フォント | ショップ全体の文字（入口・メニュー・商品詳細・店内の看板や値札）。丸ゴシック・明朝・手書き風など10種類から選べます |
| 商品の画面の背景色 | 棚の商品をクリックしたときに出る画面で、商品画像の後ろに敷く色。空欄なら商品ごとの薄い色 |
| 購入特典 | 「なし／あり」を選びます（初期は「なし」）。「あり」にすると、条件金額と特典の名前（必須）の欄が出て、カートに「あと○円で特典」、ご案内に特典の説明が出ます。特典がないイベントは「なし」のままにしてください |

- 色は、色の見本から選ぶか、横の欄にカラーコードを入れます（例：`#F7C9D8`。`F7C9D8` のように「#」なしでも、`#FAC` のような3桁でもOK）
- 色は「テーマの色に戻す」で、ベースのテーマの色に戻せます
- 画像は PNG・JPEG・WebP、8MB までです

## 入口の画面

お客さんが最初に見る画面です。右のプレビューは実際の画面と同じ表示で、「PC」「スマホ」で見え方を切り替えられます。

| 項目 | 内容 |
| --- | --- |
| 上の小さい文字・大きい見出し・見出しの下の文字 | 空欄なら「POP BASE」（お店の名前）「ブランド名」「イベント名 ― サブタイトル」 |
| お知らせ | 会期の下に表示する短いお知らせ（改行できます。空欄なら表示しません） |
| ボタンの文字 | 空欄なら「お店に入る」 |
| ロゴ画像 | 大きい見出しの代わりに表示（背景が透明な PNG がおすすめ） |
| 背景の画像 | 画面いっぱいに表示。設定すると背景の色は表示しません |
| 背景の色・文字の色 | 背景のグラデーションの上下の色、見出しとそのほかの文字の色。空欄なら「内装・イベント」で選んだテーマの配色になります（ボタンの色もテーマに合わせて変わります） |
| キャラクター | キャラクターの絵を表示するかどうか |

背景の画像を使うときは、文字が読みやすいか、プレビューの「スマホ」でも確認してください（スマホでは画像の左右が切れて表示されます）。

## キャラクター

イベントごとに、キャラクターを自由に登録できます（12体まで）。登録したキャラクターは、ご案内の「キャラクター紹介」・入口・店内の正面の壁に、上から順に並びます。
新しいイベントでは、最初に自社の4体（ハル・ビョル・タルビ・ゴミ）が入っています。不要なら削除してください。

| やりたいこと | 操作 |
| --- | --- |
| キャラクターがいないブランドのイベントにする | 「このイベントでキャラクターを使う」のチェックを外す（紹介・入口・壁のどこにも出さず、「キャラクター紹介」の見出しも消えます） |
| キャラクターを追加する | 「＋ キャラクターを追加」→ 名前（必須）・英語名・プロフィール・色を入れ、「画像を選ぶ」でイラストを設定 |
| 並び順を変える | ↑ ↓ ボタン |
| 削除する | 「削除」（アバターやほかのイベントには影響しません） |

- イラストは、背景が透明な正方形の PNG がおすすめです。画像がないうちは、選んだ色の丸に名前の頭文字が表示されます
- 名前が空のキャラクターがあると保存されません
- 「このイベントを複製」すると、キャラクターも引き継ぎます
- お客さんが選ぶアバターは、ここではなく「アバター」タブで設定します（自社の4体のアバターはこれまでどおりです）

## アバター

お客さんが入店するときに選べるアバターを設定します。キャラクター紹介・入口とは別の設定です。
右側に、お客さんのアバター選びの画面がそのまま表示されます。

| やりたいこと | 操作 |
| --- | --- |
| キャラクターをアバターから外す／戻す | 「キャラクターのアバター」で「アバターとして選べる」のチェックを外す／付ける |
| 新しいアバターを追加する | 「＋ 画像からアバターを追加」で画像を選び、名前（12文字まで）を付ける |
| 並び順を変える | ↑ ↓ ボタン |
| 削除する | 「削除」。そのアバターで入店中のお客さんは、最初のアバターの見た目になります |

- 追加できるのは12個までです
- 画像は、正面を向いた絵で、背景が透明な正方形の PNG（512×512px 程度）がおすすめです。足元が画像の下端に来るようにすると、床にきれいに立ちます
- 名前が空のアバターがあると保存されません
- キャラクターのアバターの名前と絵は、「キャラクター」タブの設定に合わせて変わります

## 確認と公開

1. 画面右のプレビューで見た目を確認します（「左の棚」「テーブル」などで視点を切り替え、ドラッグで向きを変えられます）
2. 「**下書きをサイトで確認**」を押すと、新しいタブで実際のサイトが下書きの内容で開きます（上に「下書きのプレビュー中です」と表示されます）
3. 問題なければ「**公開する**」を押します。お客さんのサイトにすぐ反映されます

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 公開前の状態に戻したい | 「公開の履歴」タブ →「公開済みの内容に戻す」で、そのイベントの下書きを捨てて公開済みの内容に戻せます |
| 「他のスタッフが先に変更を保存しました」と出た | 同時に別のスタッフが編集しています。画面が最新の内容に読み込み直されるので、必要な変更をもう一度行ってください |
| 公開したのにサイトが変わらない | お客さん側のページを再読み込みしてください |
| ログインできない | 15分の間に10回失敗すると、しばらくログインできなくなります。時間をおいてください。パスワードを忘れた場合は技術担当に再設定を依頼してください |

## アカウントの管理（技術担当）

アカウントはサーバーのフォルダで次のコマンドで管理します。パスワードは10文字以上です。

```bash
npm run admin:user -- 名前
```

```bash
npm run admin:user -- --list
```

```bash
npm run admin:user -- --delete 名前
```

同じ名前でもう一度実行すると、パスワードの変更になります。削除したアカウントは、ログイン中でもすぐに使えなくなります。
