# 店内管理画面の使い方（スタッフ向け）

店内管理画面では、次の内容をプレビューを見ながら変更できます。

| タブ | 変更できること |
| --- | --- |
| 商品の配置 | 棚・テーブルにどの商品を置くか |
| 内装・イベント | 会期・看板・壁紙・床・色・**ショップの基本フォント**・購入特典 |
| 入口の画面 | お客さんが最初に見る「お店に入る」前の画面の文字・画像・色 |
| キャラクター | イベントごとのキャラクターの登録（追加・削除・並び順・名前・プロフィール・色・イラスト）。キャラクターを使わない設定も |
| アバター | お客さんが入店するときに選べるアバター（登録したキャラクター、いなければ自社の4体。画像から追加もできる） |

- 開き方：サイトのアドレスの後ろに `/admin` を付けて開きます（例: `https://popup.example.com/admin`）
- 商品そのもの（名前・価格・在庫・写真）は、これまでどおり **Shopify 管理画面** で編集します

## イベントごとの管理

ポップアップ（イベント）ごとに、内装・棚の配置・入口の画面・キャラクター・アバター・会期を別々に設定できます。
ログインすると、最初に **イベント一覧** が出ます。「開催中」「開催予定」「準備中（未公開）」「終了」に分かれて並び、
いまお客さんに出ているイベントには「お客さんに表示中」と付きます。「編集する」でそのイベントの編集画面に進みます。
編集画面の左上の「← イベント一覧」で一覧に戻れます（上部の「イベント」の選択欄で、ほかのイベントに直接切り替えることもできます）。

| やりたいこと | 操作 |
| --- | --- |
| 新しいイベントを作る | イベント一覧の「＋ 新しいイベント」→ イベント名を入れる |
| 前のイベントの設定を引き継いで作る | イベント一覧で引き継ぎたいイベントの「複製」（編集画面では「このイベントを複製」）。内装・入口の画面・キャラクター・アバター・棚の配置などがコピーされます（イベント名・会期・営業時間・コレクションは新しく設定） |
| 店内に並べる商品を決める | 「内装・イベント」→「**Shopify のコレクション**」で、Shopify で作ったコレクションを選ぶ（必須） |
| イベントを削除する | 「削除」。お客さんに表示中のイベントは削除できません |

**お客さんのサイトに出るイベントは、会期で自動で決まります。**

1. 公開したイベントのうち、**会期中**（開始日時〜終了日時）のもの
2. 会期中のものがなければ、**次に始まる**もの（入口にそのイベントの情報と、**オープンまでのカウントダウン**）
3. 次の予定もなければ（イベントがない・最後のイベントが終わった）、**POP BASE だけの画面**（「次のポップアップを準備中です」。ブランド・キャラクター・店内は出しません）

**1つの期間に開けるイベントは1つです。** ほかのイベントと会期が重なる日時は入れられません（入れると元に戻り、重なっているイベントの名前と会期が表示されます）。前のイベントの終了日時と、次のイベントの開始日時を同じにするのは大丈夫です。

次のイベントは、前もって作って「サイトに反映する」まで済ませておけば、開始日時になると自動で切り替わります。
イベント名の横の［開催中］［開催予定］［終了］［未公開］で状態がわかります。「お客さんに表示中」が付いているものが、いまサイトに出ているイベントです。

### Shopify のコレクションの準備

1. Shopify の「商品管理 → コレクション」で、イベントごとにコレクションを作り（例：「春のフェア」）、そのイベントで売る商品を入れます
2. 商品とコレクションが、販売チャネル「Headless」に公開されていることを確認します
3. 店内管理画面でイベントを選び、「Shopify のコレクション」でそのコレクションを選びます。「商品の配置」に、そのコレクションの商品が並びます

## 入力欄の「必須」「任意」

入力欄の名前の横に、次の印が付いています。

| 印 | 意味 |
| --- | --- |
| **必須** | 入れないと公開できません（ブランド名・イベント名・開始日時・終了日時） |
| **任意・空欄なら○○** | 空欄のままなら ○○（テーマの色・初期の文字など）が使われます |
| **任意・空欄なら非表示** | 空欄のままなら店内に表示しません（棚の看板など） |

必須の欄が空欄のときは、画面上部に「必須項目が未入力」と表示され、その欄が赤くなります。

## 基本の流れ

```
編集する → 自動で下書きに保存 → 「下書きをサイトで確認」 → 「サイトに反映する」でお客さんに反映
```

- 編集した内容は、1秒ほどで自動的に **下書き** として保存されます。画面上部の「**保存**」ボタン（または Ctrl+S / ⌘+S）で、すぐに保存することもできます（保存が済むと「保存済み ✓」になります）
- 下書きは、**「サイトに反映する」を押すまでお客さんには見えません**
- 画面上部の表示で状態がわかります
  - 「未公開の変更があります」… 下書きに、まだ公開していない変更がある
  - 「公開中と同じ内容です」… 下書きと公開中が同じ

## 商品の配置

左に商品の一覧、右に「左の棚」「中央のテーブル」「右の棚」の枠があります。
棚は 2段 × 5枠、テーブルは 5枠です。
それぞれの枠の上に、看板の文字（英字・日本語）の欄があります。空欄の行は表示せず、両方とも空欄なら看板（テーブルは前面の文字）を出しません。

| やりたいこと | 操作 |
| --- | --- |
| 商品を置く | 左の一覧から枠へドラッグ（または、商品をクリック → 枠をクリック） |
| 同じ商品をいくつも置く | 同じ商品を、別の枠にもう一度ドラッグ。**在庫数まで** 置けます（在庫2個なら2か所まで。在庫数を管理していない商品は制限なし） |
| 置き場所を動かす | 枠から別の枠へドラッグ。商品がある枠に落とすと入れ替わります |
| 店内から外す | 枠の右上の「×」、または枠から左の一覧へドラッグ |
| まだ置いていない商品を探す | 一覧の上の「未配置だけ」にチェック |
| 最初からやり直す | 「自動で並べ直す」（商品の種類に合わせて自動で並べます） |

- 一覧の商品の下に「左の棚 下段 2番 ほか1か所」のように、今の置き場所が表示されます。置いた商品は少し暗く、在庫数まで置き終わった（もう置けない）商品はさらに暗く表示されます
- 置いていない商品は、お客さんのサイトには表示されません

## 内装・イベント

| 項目 | 内容 |
| --- | --- |
| ブランド名 | 店内の看板の上の行、ページ上部のロゴ、入口の大きい見出し（入口で別に設定していない場合）。全角15文字・半角30文字まで |
| イベント名 | 店内の看板の大きい文字と入口。長さに合わせて看板の幅が広がります。全角14文字・半角28文字まで |
| 開始日時・終了日時 | この時間だけお店が開きます（日本時間）。開始前は入口に「○日 ○時 オープン」、終了後は「このポップアップは終了しました」と表示され、入店できません |
| 毎日の開店・閉店時刻 | 会期中の毎日の営業時間。空欄なら会期中は24時間営業。営業時間外は「本日の営業は終了しました」と表示 |
| 会期の表示文 | 看板の右の札・入口・ご案内に出す文。空欄なら日時から自動で作ります |

閉店の5分前から、店内に「閉店まで」のタイマーが出て、閉店時刻になると店内のお客さんは自動で退店します（カートは空になります）。
入力欄の下の「この設定でサイトに反映すると、今は ○○」で、反映したときの状態を確認できます。
| ベースのテーマ | Milk Tea（初期設定）・Soft Pink・Lavender Dream・Sage Mint・Powder Blue の5種類から選びます。壁・床・看板などの色を個別に指定しているときは、テーマを変えると「テーマの配色にそろえますか？」と確認が出ます（OKで個別の色を消してテーマの色に）。ほかの項目で空欄のものは、このテーマの値になります |
| 壁紙の画像 | 横長の画像（例: 2048×540px）。横に繰り返して貼られます。指定すると「壁の柄」より優先されます |
| 壁の色・柄・腰壁・見切りの色 | 画像を使わないときの壁のデザイン |
| 床の画像・種類・色 | 床のデザイン |
| 中央のテーブルの下の色 | テーブルの下に敷く楕円の色。空欄ならテーマの色（少し透けた色） |
| 看板の色 | 看板の地の色、正面の看板のイベント名の色・ブランド名の色（棚やテーブルの看板の文字はテーマの色）。照明はいつも明るい設定です |
| フォント | ショップ全体の文字（入口・メニュー・商品詳細・店内の看板や値札）。丸ゴシック・明朝・手書き風など10種類から選べます |
| アバターの下の円の色 | 店内で、自分のアバターの足元に出る円の色。空欄ならテーマの色 |
| キャラクター紹介文の背景色 | 店内の壁のキャラクターをタップしたときに出る紹介文の背景の色（文字の色は自動で読みやすい色）。空欄ならテーマの色 |
| 商品の画面の背景色 | 棚の商品をクリックしたときに出る画面で、商品画像の後ろに敷く色。空欄なら商品ごとの薄い色 |
| 店内の上限人数 | 同時に店内に入れる人数（10・20・30・40・50人。初期は50人）。いっぱいのときは入口で順番待ちになります。変えても、いま店内にいる人は退店しません |
| 送料・発送・お支払い | **返品・交換・キャンセルについて**：ご案内（と入口の「ご利用案内」）に出す文。記入欄には最初から標準の文が入っています（空欄にしても、お店には標準の文が出ます）。**お支払い方法（必須）**：ご案内の「お支払い方法」に出す文（実際に使える方法は Shopify の「設定 → 決済」と同じに）。そのほか、会期・営業時間のすぐ下。**送料（必須）**：ご案内の「送料」に出す文（改行可・300文字まで）。送料無料になる金額（任意）：入れると、カートで送料を「無料」と表示し、届かないときは「あと○円で送料無料」と表示します。**発送について（必須）**。実際にお会計で請求される送料は Shopify の「設定 → 配送」で決まるので、文と金額をそろえてください。カートの送料は「お会計時に計算」と表示します |
| 購入特典 | 「なし／あり」を選びます（初期は「なし」）。「あり」にすると、特典の条件金額と特典の名前（どちらも必須）の欄が出て、カートに「あと○円で特典」、ご案内に特典の説明が出ます。特典がないイベントは「なし」のままにしてください |

- 色は、色の見本から選ぶか、横の欄にカラーコードを入れます（例：`#F7C9D8`。`F7C9D8` のように「#」なしでも、`#FAC` のような3桁でもOK）
- 色は「テーマの色に戻す」で、ベースのテーマの色に戻せます
- 画像は PNG・JPEG・WebP、8MB までです

## 入口の画面

お客さんが最初に見る画面です。右のプレビューは実際の画面と同じ表示で、「PC」「スマホ」で見え方を切り替えられます。

| 項目 | 内容 |
| --- | --- |
| 大きい見出し・イベント名 | 空欄なら「ブランド名」「イベント名」（いちばん上は、いつもお店のロゴ「POP BASE」） |
| 会期 | 入口には、会期（と営業時間）をいつも表示します（入力は不要） |
| ボタンの文字 | 空欄なら「お店に入る」 |
| ロゴ画像 | 大きい見出しの代わりに表示（背景が透明な PNG がおすすめ） |
| 背景の画像 | 画面いっぱいに表示。設定すると背景の色は表示しません |
| 背景の色・文字の色 | 背景のグラデーションの上下の色、見出しとそのほかの文字の色。空欄なら「内装・イベント」で選んだテーマの配色になります（ボタンの色もテーマに合わせて変わります） |
| キャラクター | キャラクターの絵を表示するかどうか |

背景の画像を使うときは、文字が読みやすいか、プレビューの「スマホ」でも確認してください（スマホでは画像の左右が切れて表示されます）。

## キャラクター

イベントごとに、キャラクターを自由に登録できます（12体まで）。登録したキャラクターは、ご案内の「キャラクター紹介」・入口・店内の正面の壁に、上から順に並びます。
新しいイベントでは、最初に初期の4体（モク・キラリ・ルナ・ポム）が入っています。不要なら削除してください。

| やりたいこと | 操作 |
| --- | --- |
| キャラクターがいないブランドのイベントにする | 「このイベントでキャラクターを使う」のチェックを外す（紹介・入口・壁のどこにも出さず、「キャラクター紹介」の見出しも消えます） |
| キャラクターを追加する | 「＋ キャラクターを追加」→ 名前（必須）・英語名・プロフィールを入れ、「画像を選ぶ」でイラストを設定 |
| 並び順を変える | ↑ ↓ ボタン |
| 削除する | 「削除」（アバターからも外れます。ほかのイベントには影響しません） |
| ご案内の「キャラクター紹介」の背景色を変える | それぞれのキャラクターの「紹介の背景色」で、淡い色（ミズイロ・クリーム・ラベンダー・ピンク・ミント・ピーチ・ミルクティー・グレー）から選ぶか、HEXで指定（空欄ならキャラクターの色を淡くした色）。アバターを選ぶ画面の枠も同じ色になります |

- キャラクターどうしの大きさは、**画像の高さ（ピクセル数）の比率** で決まります。いちばん高いキャラクターを 100% として、ほかはその比率で小さく表示します（店内の壁・アバター・入口・キャラクター紹介・アバター選びのすべて）。例：高さ 600px・600px・400px の画像なら、3体目は 2/3 の大きさ。画像の上下の透明な余白は数えません
- イラストは、背景が透明な正方形の PNG がおすすめです。画像がないうちは、淡いラベンダーの丸に名前の頭文字が表示されます
- 名前が空のキャラクターがあると保存されません
- 「このイベントを複製」すると、キャラクターも引き継ぎます
- 登録したキャラクターは、アバターとしても選べるようになります（アバターから外すのは「アバター」タブで）

## アバター

お客さんが入店するときに選べるアバターを設定します。
「キャラクター」タブでキャラクターを登録しているイベントでは、**そのキャラクターだけ** がアバターになります。登録していない（または「キャラクターを使う」をオフにした）イベントでは、初期の4体（モク・キラリ・ルナ・ポム）がアバターになります。
右側に、お客さんのアバター選びの画面がそのまま表示されます。

| やりたいこと | 操作 |
| --- | --- |
| キャラクターをアバターから外す／戻す | 「キャラクターのアバター」で「アバターとして選べる」のチェックを外す／付ける |
| 新しいアバターを追加する | 「＋ 画像からアバターを追加」で画像を選び、名前（12文字まで）を付ける |
| 並び順を変える | ↑ ↓ ボタン |
| 削除する | 「削除」。そのアバターで入店中のお客さんは、最初のアバターの見た目になります |

- 追加できるのは12個までです
- 画像は、正面を向いた絵で、背景が透明な正方形の PNG（512×512px 程度）がおすすめです。足元が画像の下端に来るようにすると、床にきれいに立ちます
- 名前が空のアバターがあると保存されません
- キャラクターのアバターの名前と絵は、「キャラクター」タブの設定に合わせて変わります

## 確認と公開

1. 画面右のプレビューで見た目を確認します（「左の棚」「テーブル」などで視点を切り替え、ドラッグで向きを変えられます）
2. 「**下書きをサイトで確認**」を押すと、新しいタブで実際のサイトが下書きの内容で開きます（上に「下書きのプレビュー中です」と表示されます）
3. 問題なければ「**サイトに反映する**」を押します。お客さんのサイトにすぐ反映されます

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 公開前の状態に戻したい | 「公開の履歴」タブ →「公開済みの内容に戻す」で、そのイベントの下書きを捨てて公開済みの内容に戻せます |
| 「他のスタッフが先に変更を保存しました」と出た | 同時に別のスタッフが編集しています。画面が最新の内容に読み込み直されるので、必要な変更をもう一度行ってください |
| 公開したのにサイトが変わらない | お客さん側のページを再読み込みしてください |
| ログインできない | 15分の間に10回失敗すると、しばらくログインできなくなります。時間をおいてください。パスワードを忘れた場合は技術担当に再設定を依頼してください |

## 出品者のアカウント

出品者（企業・ブランド・クリエイター）にも、管理画面のアカウントを渡せます。

| | 運営 | 出品者 |
| --- | --- | --- |
| 見られるイベント | すべて | 担当のイベントだけ |
| イベントを作る・複製・削除 | できる | できない |
| 内装・入口の画面・キャラクター・アバター・商品の配置 | できる | できる |
| 会期・営業時間・上限人数・コレクション・送料・支払い・返品・購入特典 | できる | 見えるが変えられない（「運営が設定します」） |
| サイトへの反映 | 「サイトに反映する」 | 「反映の確認を依頼する」→ 運営が確認して反映 |
| 商品の申請 | 確認・画像のダウンロード・状態の変更 | 申請する・直す |
| 注文 | 見られる | 担当のイベントの注文だけ見られる |
| アカウントの管理 | できる | できない |

### アカウントを作る（運営）
1. 上の「アカウント」を開く
2. ID・パスワード（10文字以上）・権限「出品者」・担当のイベントを選んで「追加する」
3. ID とパスワードを、ご本人に別の方法（電話・メッセージなど）でお伝えください

担当のイベントの変更・パスワードの再設定は、一覧の「変更」から。

### 反映の確認依頼
出品者が「反映の確認を依頼する」を押すと、イベント一覧に「反映の確認依頼あり」と出ます。お問い合わせのメール設定があれば、運営にメールも届きます。
内容を確認して「サイトに反映する」を押すと、依頼は消えます。

### 商品の申請 → Shopify に登録
1. 出品者が「商品の申請」タブで、商品名・価格・在庫数・大きさ・説明と画像（5枚まで）を申請します（運営にメールも届きます）
2. 運営は「商品の申請」タブで「画像と一覧をまとめてダウンロード（ZIP）」。ZIP の中は、商品ごとのフォルダに画像、全体の一覧が「商品一覧.csv」です
3. Shopify に商品を登録して、イベントのコレクションに入れます（棚での大きさはメタフィールド「棚での大きさ」に）
4. 申請の状態を「Shopifyに登録済み」にします。直してほしいときは「差し戻し」にして、メモに理由を書きます（出品者の画面に出ます）

### 注文（出品者が発送）
「注文」タブに、そのイベントの商品が入った注文（お届け先・商品・数量）が出ます。「未発送だけ」で絞り込み、「CSV でダウンロード」で Excel などに取り込めます。
Shopify のアプリに注文を読む権限が必要です（[shopify-setup.md](shopify-setup.md)）。

## アカウントの管理（技術担当）

管理画面の「アカウント」（運営のみ）のほか、サーバーのフォルダのコマンドでも管理できます（コマンドで作ったアカウントは「運営」になります）。

パスワードは10文字以上です。

```bash
npm run admin:user -- 名前
```

```bash
npm run admin:user -- --list
```

```bash
npm run admin:user -- --delete 名前
```

同じ名前でもう一度実行すると、パスワードの変更になります。削除したアカウントは、ログイン中でもすぐに使えなくなります。
