# Shopify 連携の設定手順

バーチャルポップアップの **商品・在庫・価格・決済**、**店内の置き場所**、**内装（壁紙・床・色）と会期** は、
すべて Shopify の管理画面から変更できます。サイトのファイルを書き換える必要はありません（保存後、ページを再読み込みすると反映されます）。

初期設定は1回だけで、技術担当の方が行ってください（30分ほど）。日々の運用はスタッフの方が「[運用編](#運用編スタッフ向け)」の操作だけで行えます。

---

## 初期設定（1回だけ）

### 1. Storefront API のトークンを発行する

1. Shopify 管理画面 → **販売チャネル** → 「**Headless**」チャネルを追加（Shopify App Store から無料で追加できます）
2. Headless → **ストアフロントを作成**
3. 「Storefront API」の **権限** で次をオンにする
   - 商品の閲覧（`unauthenticated_read_product_listings`）
   - 商品の在庫の閲覧（`unauthenticated_read_product_inventory`）※在庫数「残りわずか」の表示に使います。オフでも動きます
   - チェックアウトの作成（`unauthenticated_write_checkouts`）／カートの閲覧・作成
   - メタオブジェクトの閲覧（`unauthenticated_read_metaobjects`）
4. **公開アクセストークン**（public access token）をコピー
5. サイトの `js/data.js` の `SHOPIFY_CONFIG` に入力

```js
window.SHOPIFY_CONFIG = {
  domain: 'your-store.myshopify.com',
  storefrontToken: 'ここに公開アクセストークン',
  apiVersion: '2025-01',
  collection: 'popup',
  eventHandle: 'current',
};
```

> 公開アクセストークンはブラウザに公開される前提のトークンなので、サイトに書いて問題ありません。
> 「Admin API」のトークン（`shpat_` で始まるもの）は**絶対に**書かないでください。

### 2. コレクションを作る

- **商品管理 → コレクション** で、ハンドルが `popup` のコレクションを作成します（手動コレクションでOK）。
- このコレクションに入れた商品が店内に並びます。
- 商品が **Headless チャネルに公開** されていることを確認してください（商品ページの「販売チャネル」）。

### 3. 商品メタフィールドを定義する

**設定 → カスタムデータ → 商品 → 定義を追加** で次を作成します。
どれも「**ストアフロントからのアクセス**（Storefront API アクセス）」を**オン**にしてください。

| 名前（管理画面での表示） | ネームスペースとキー | 種類 | 選択肢・内容 |
| --- | --- | --- | --- |
| 店内の置き場所 | `popup.zone` | 単一行テキスト（選択肢を制限） | `左の棚` / `右の棚` / `限定テーブル` / `置かない` |
| 並び順 | `popup.order` | 整数 | 小さい順に左から並ぶ |
| キャラクター | `popup.character` | 単一行テキスト（選択肢を制限） | `ハル` / `ビョル` / `タルビ` / `ゴミ` |
| 会場限定 | `popup.limited` | true / false | オンで「会場限定」マーク |
| お一人様の購入上限 | `popup.purchase_limit` | 整数 | 例: 1 |
| 棚での大きさ | `popup.size` | 単一行テキスト（選択肢を制限） | `大` / `中` / `小` |
| 仕様（サイズ・素材） | `popup.spec` | 単一行テキスト | 例: 約 W24 × H20cm / ポリエステル |

そのほか、商品の通常の項目は次のように使われます。

| Shopify の項目 | 店内での使われ方 |
| --- | --- |
| 商品名・説明・価格 | 商品詳細・値札 |
| 商品画像（1枚目） | 棚に並ぶ姿（**背景を透明にした PNG・正方形** がおすすめ） |
| 商品タイプ | 商品一覧のカテゴリ |
| タグ `new` | NEW マーク |
| 在庫 | 0 で SOLD OUT。5 以下で「残りわずか」 |

### 4. メタオブジェクト「POP UPイベント」を定義する

**設定 → カスタムデータ → メタオブジェクト → 定義を追加**

- 名前: `POP UPイベント`、タイプ: **`popup_event`**
- 「**ストアフロントからのアクセス**」を**オン**
- 次のフィールドを追加します（すべて任意。空欄はテーマの初期値が使われます）

| フィールド名 | キー | 種類 | 内容 |
| --- | --- | --- | --- |
| イベント名 | `title` | 単一行テキスト | 看板の大きな文字（例: Winter Market） |
| サブタイトル | `subtitle` | 単一行テキスト | 例: ハヌルの冬じたく |
| 会期 | `period` | 単一行テキスト | 例: 2026.12.01 – 12.31 |
| ベースのテーマ | `theme_preset` | 単一行テキスト（選択肢） | `sky` / `night` / `holiday` / `spring` |
| 壁紙の画像 | `wall_image` | ファイル（画像） | 指定すると柄より優先。横に繰り返して貼られます |
| 壁の色 | `wall_color` | 色 | |
| 壁の柄 | `wall_pattern` | 単一行テキスト（選択肢） | `clouds` / `stars` / `flowers` / `hearts` / `dots` / `stripes` / `gingham` / `none` |
| 柄の色 | `wall_pattern_color` | 色 | |
| 腰壁の色 | `lower_color` | 色 | 壁の下半分 |
| 見切りの色 | `trim_color` | 色 | 腰壁の上のライン |
| 床の画像 | `floor_image` | ファイル（画像） | 指定すると床の種類より優先 |
| 床の種類 | `floor_style` | 単一行テキスト（選択肢） | `wood` / `check` / `tile` / `carpet` |
| 床の色1・2 | `floor_color_1` / `floor_color_2` | 色 | |
| 看板の色・文字色 | `sign_color` / `sign_text_color` | 色 | |
| 照明 | `light` | 単一行テキスト（選択肢） | `day` / `night` |
| 特典の条件金額 | `novelty_threshold` | 整数 | 例: 3000 |
| 特典の名前 | `novelty_name` | 単一行テキスト | |
| 左の棚の看板（英字・日本語） | `left_title` / `left_label` | 単一行テキスト | |
| 右の棚の看板（英字・日本語） | `right_title` / `right_label` | 単一行テキスト | |

定義ができたら **コンテンツ → メタオブジェクト → POP UPイベント → エントリーを追加** で1件作り、
ハンドルを **`current`** にします。

### 5. ガチャのクーポンを作る

**割引** で次のディスカウントコードを作成します（`js/data.js` の `GACHA_PRIZES` と同じコード）。

| コード | 割引 |
| --- | --- |
| HANEUL5 | 5% |
| HANEUL10 | 10% |
| HANEUL15 | 15% |
| HANEUL20 | 20% |

> ガチャはお客さんのブラウザで抽選しているため、コードを知った人が SNS などで共有する可能性があります。
> 「お客様1人につき1回まで」「期間をイベント会期に限定」の設定を必ず入れてください。

## 運用編（スタッフ向け）

| やりたいこと | 操作 |
| --- | --- |
| 商品を店内に並べる | 商品をコレクション `popup` に入れ、メタフィールド「店内の置き場所」を選ぶ |
| 棚の並び順を変える | メタフィールド「並び順」の数字を変える |
| 一時的に店内から外す | 「店内の置き場所」を `置かない` にする（商品一覧からも消えます） |
| 価格・在庫・説明を変える | いつもどおり商品ページで編集 |
| 壁紙を変える | POP UPイベント（current）の「壁紙の画像」に画像をアップロード |
| テーマごと変える | 「ベースのテーマ」を選び直し、必要なら色・画像を上書き |
| 会期・看板の文字を変える | 「イベント名」「サブタイトル」「会期」を編集 |
| 次のイベントを準備しておく | 新しいエントリーを作っておき、切り替え日に `js/data.js` の `eventHandle` を変える（またはハンドルを入れ替える） |

保存したら、サイトを再読み込みすると反映されます。

### 壁紙・商品画像のコツ

- **商品画像**: 背景を透明にした PNG、正方形、1000px 程度。下端に商品が接するように置くと、棚にきれいに立ちます。
- **壁紙画像**: 横長（例: 2048 × 540px）。左右がつながるデザインにすると継ぎ目が目立ちません。下 3 割ほどは腰壁で隠れます（腰壁の色を壁と同じにすると目立たなくなります）。

### 注意

- 「お一人様の購入上限」はサイト上のカートで制限しています。購入手続きの段階でも確実に止めたい場合は、
  Shopify の購入数制限アプリ（またはチェックアウトの検証機能）を併用してください。
