# お買い物を POP BASE だけで完結させる（Shopify の画面の設定）

お客さんが見るのは **POP BASE（popbase.jp）** と、**POP BASE のデザインにしたお会計画面** だけにします。
Shopify のお店のページ（商品一覧など）は、お客さんの目に触れないようにします。

> カード番号を入れるお会計画面は、セキュリティの決まりで Shopify のものを使います（POP BASE のページの中には作れません）。
> そのかわり、ロゴ・色・アドレスを POP BASE にそろえます。

できあがりの流れ：

```
popbase.jp で商品を選ぶ → カート → 「購入手続きへ」
  → お会計画面（POP BASE のロゴと色。アドレスは shop.popbase.jp）
  → 注文完了 →「買い物を続ける」で popbase.jp に戻る
```

| 手順 | やること | 誰が |
| --- | --- | --- |
| 1 | お会計画面を POP BASE のデザインにする | Shopify 管理画面 |
| 2 | お会計画面のアドレスを shop.popbase.jp にする（任意） | Xserver ＋ Shopify 管理画面 |
| 3 | 移動専用テーマを入れる | Shopify 管理画面（テーマは用意済み） |
| 4 | 規約・ポリシーを入力し、POP BASE の中で表示する | Shopify 管理画面・Dev Dashboard |
| 5 | 注文確認メールを POP BASE のデザインにする | Shopify 管理画面 |
| 6 | 通しで試す | — |

---

## 1. お会計画面を POP BASE のデザインにする

1. Shopify 管理画面 → **設定 → チェックアウト** →「**カスタマイズ**」
2. 左の「**ブランディング**」（筆のアイコン）で、次を設定して「保存」
   - **ロゴ**：`images/logo/` の POP BASE のロゴ（横長のもの）。大きさは「小」〜「中」
   - **色**：アクセント（ボタンなど）に POP BASE の濃い色 `#2E2729`（サイトのボタンと同じ）かラベンダー `#9B80E0`、背景は白か `#FFF4F1`
   - **フォント**：見出し・本文とも、ゴシック体（Noto Sans JP など）
3. 右上の「**…**」→「**プレビュー**」で、スマホとパソコンの見た目を確かめる

## 2. お会計画面のアドレスを shop.popbase.jp にする（任意）

アドレスバーが `popbase.myshopify.com` ではなく `shop.popbase.jp` になり、別のサイトに移った感じがなくなります。

1. **Xserver**（ドメインの DNS レコード設定）で、次のレコードを **追加** します（今ある popbase.jp と www のレコードはそのまま）

   | ホスト名 | 種別 | 内容 |
   | --- | --- | --- |
   | shop.popbase.jp | CNAME | shops.myshopify.com |

2. Shopify 管理画面 → **設定 → ドメイン** →「**既存のドメインを接続**」→ `shop.popbase.jp` を入力 →「確認」
   - 反映まで数十分〜数時間かかることがあります。「接続済み」になるまで待ちます
3. 同じ画面で、`shop.popbase.jp` を **メインのドメイン（プライマリ）** にします
   - お会計画面・注文確認メールのリンクが shop.popbase.jp になります

> **注意**：`popbase.jp`（www なし・あり）は POP BASE のサイト（Render）につながっています。Shopify に接続するのは **shop.popbase.jp だけ** です。

## 3. 移動専用テーマを入れる

Shopify のお店のページを開いた人を、自動で popbase.jp に移動させるテーマです（リポジトリの `shopify-theme/`）。
お会計の後の「買い物を続ける」もこのテーマで popbase.jp に戻ります。

1. リポジトリにある **`shopify-theme.zip`** をダウンロードします（中身を変えたときは `npm run theme:zip` で作り直せます）
2. Shopify 管理画面 → **オンラインストア → テーマ** →「**テーマを追加**」→「**zip ファイルをアップロード**」→ `shopify-theme.zip`
3. アップロードした「POP BASE（移動専用）」の「**…**」→「**公開**」
4. **オンラインストア → 各種設定** の「**パスワード保護**」をオフにします
   - オンのままだと、「買い物を続ける」で Shopify のパスワード画面が出てしまいます
   - テーマが移動させるので、オフにしても Shopify のお店のページはお客さんに見えません
5. 確かめる：`https://popbase.myshopify.com`（2 をした場合は `https://shop.popbase.jp`）を開くと、popbase.jp に移動します

> 規約・ポリシーのページ（`/policies/…`）とギフトカードのページだけは、移動せずにそのまま表示します。

## 4. 規約・ポリシーを入力し、POP BASE の中で表示する

1. Shopify 管理画面 → **設定 → ポリシー** で、次の6つを入力して保存
   - 特定商取引法に基づく表記（ネット販売では必須）／プライバシーポリシー／返金ポリシー／配送ポリシー／利用規約／連絡先情報（お問い合わせ）
2. **Dev Dashboard** の店内管理用アプリ（`POP BASE 店内管理`）の **バージョン（設定）** で、Admin API のスコープに **`read_legal_policies`** を追加 → 新しいバージョンを **リリース**
3. ストアの管理画面でアプリの更新（権限の追加）を **承認** します（「アプリ」の一覧に案内が出ます）
4. 確かめる：popbase.jp のページ下のリンクを押すと、**POP BASE の中のウィンドウ** に文章が出ます（変更は10分以内に反映）

権限がないとき・未入力の項目は、これまでどおり Shopify のページ（`/policies/…`）へのリンクになります。

## 5. 注文確認メールを POP BASE のデザインにする

1. Shopify 管理画面 → **設定 → 通知** →「**ブランディングをカスタマイズ**」
2. ロゴ（POP BASE）と色（ラベンダー `#9B80E0` など）を設定して保存
3. 「注文確認」などのメールを開いて「**プレビュー**」で確かめる

## 6. 通しで試す

1. popbase.jp で入店 → 商品をカートに入れる →「購入手続きへ」
2. お会計画面のロゴ・色・アドレス（shop.popbase.jp）を確かめる
3. テスト用の支払い（Shopify の「Bogus Gateway」など）で注文まで進める
4. 注文完了の画面で「**買い物を続ける**」→ popbase.jp に戻ることを確かめる
5. 注文確認メールのデザインを確かめる
6. Shopify のお店のアドレスを直接開いても、popbase.jp に移動することを確かめる
