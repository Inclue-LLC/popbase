# POP BASE 用の Shopify テーマ（移動専用）

お客さんが Shopify のお店のページ（`https://popbase.myshopify.com/…` など）を開いたときに、POP BASE（https://popbase.jp）へ移動させるだけのテーマです。

- お会計（チェックアウト）・注文状況のページはテーマを使わないので、そのまま Shopify で表示されます
- お会計のあとの「買い物を続ける」も、このテーマで POP BASE に戻ります
- 規約・ポリシーのページ（`/policies/…`）とギフトカードのページは、移動せずに表示します

## 入れ方

1. リポジトリの上の階層で `npm run theme:zip` を実行すると、`shopify-theme.zip` ができます
2. Shopify 管理画面 →「オンラインストア → テーマ」→「テーマを追加 → zip ファイルをアップロード」で、その zip を選びます
3. アップロードしたテーマの「…」→「公開」

移動先を変えるときは、テーマの「カスタマイズ → テーマ設定 → 移動先」で変えられます。
